# Tic-Tac-Toe

A simple Tic-Tac-Toe game built with HTML, CSS, and JavaScript.

## About This Project

Perhaps this is one of the most difficult projects I have worked on so far.

HTML and CSS feel easier to me because they are more predictable. JavaScript was different because this project required me to understand logic, state, functions, conditions, events, and how different parts of the code work together.

I had to search Google many times, but I often found that different websites explained the same concept using many technical words. I could usually understand the general idea, but sometimes I struggled with the basic concepts that looked simple but actually had deeper meanings.

Because of that, I started using AI in a different way.

Instead of asking AI to give me the complete solution, I asked it to challenge me with small tasks. I would try to solve each task myself, and whenever I became confused, I asked for an explanation. This approach felt similar to completing FreeCodeCamp tasks, where the goal is not only to finish the task but also to understand what is happening behind each line.

That made this project much more valuable to me.

## What I Learned

### Functions

Functions became much more familiar to me during this project.

I learned that a function can save repeated lines of code by putting reusable behavior in one place.

For example, instead of repeating the same code in different places, I can create a function and reuse it.

### Boolean Values

I was surprised by how useful `true` and `false` are.

They became especially useful when working with `if` and `else if` conditions and when controlling the state of the game.

### `return`

I learned that `return` is not only used to give a value back from a function.

It can also stop the function from continuing to execute.

### Factory Functions

The factory function concept became easier for me after thinking about it like a factory worker.

The factory receives information and creates objects from it.

For example, my player factory creates different player objects from a name and symbol.

### DOM and `textContent`

I learned that JavaScript can change what appears on the webpage.

Using `textContent`, I was able to display things such as the current player's turn, the winner, and a tie directly on the webpage.

### `forEach()`

I became more familiar with `forEach()` by using it to work with every square on the board.

Instead of manually handling each button, I could perform an action for every element.

### `const`, variables, and objects

I also became more comfortable with `const`, `let`, objects, DOM elements, properties, and values.

Some of these concepts looked simple at first, but working on an actual project helped me understand what they really mean.

## What This Project Taught Me

The biggest lesson was not simply how to make a Tic-Tac-Toe game.

It was becoming more familiar with JavaScript.

For me, that is one of the most important parts of learning programming.

As long as I become more familiar with JavaScript and understand how to put different concepts together, that is progress, regardless of whether my code is perfect.

My main priority is to understand enough first, and then improve my code step by step.
